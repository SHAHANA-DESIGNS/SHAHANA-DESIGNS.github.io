# Shahana — Portfolio Website

A polished, responsive, single-page portfolio built from the public GitHub archive at `github.com/SHAHANA-DESIGNS`.

## Included
- Editorial / art-studio visual direction
- Responsive navigation
- Hero section and studio positioning
- Selected work: original art, Hindi Primer, Market Moment
- 15-piece artwork gallery with image lightbox
- Credentials section referencing 12 public certificate scans
- Hindi Primer showcase
- Resume + GitHub CTAs
- Contact / commission section
- Scroll reveal animations
- No build tools required

## Deploy to GitHub Pages

1. Create or update the repository `SHAHANA-DESIGNS.github.io`.
2. Put `index.html`, `styles.css`, and `script.js` in the repository root.
3. Commit and push.
4. In GitHub: Settings → Pages → deploy from the `main` branch / root.
5. Your site will be available at `https://shahana-designs.github.io/` if the GitHub account/repository configuration matches.

## Before publishing

Replace `your-email@example.com` in `index.html` with the real studio email address.

The site currently references the public artwork/certificate files from GitHub Raw, so the source repositories should remain public. For maximum independence and speed, copy the images into an `assets/` folder and change the image paths to local files.
